# گزارش بررسی امنیت اندروید — توپهای همزاد ۱٫۹

**دامنه:** بازبینی ایستای کد بازی `mirror/src/main`، مانیفست، تنظیمات Gradle، منابع صوتی/تصویری و فونت، ابزارهای ساخت، workflowهای مخزن، و برنامهٔ نمونهٔ `app`. این ارزیابی ممیزی رسمی، مهندسی معکوس همهٔ فایل‌های دودویی، تست نفوذ، بررسی همهٔ CVEهای زنجیرهٔ تأمین یا آزمون پویا روی دستگاه واقعی نیست. نبود یافتهٔ مشکوک اثبات نبود بدافزار نیست.

## یافتهٔ بحرانی حل‌نشده: کلید امضای عمومی

فایل کلید توسعه و گذرواژهٔ آن از نسخه‌های قبلی در مخزن و تاریخچهٔ Git عمومی‌اند. هر شخصی می‌تواند با همان کلید یک APK دیگر را امضا کند؛ بنابراین مطابقت گواهی به‌تنهایی اصالت سازنده را ثابت نمی‌کند و این APK برای توزیع تولیدی قابل‌اعتماد نیست. حذف فایل از نسخهٔ جاری تاریخچه و کپی‌های عمومی را امن نمی‌کند. پیکربندی محلی اکنون امضای Release با کلید افشاشده را نمی‌پذیرد و فایل کلید از نسخهٔ جاری در حال حذف است، اما کلید تازه هنوز ایجاد نشده و نسخهٔ ۱٫۹ ساخته نشده است. نسخه‌های منتشرشدهٔ پیشین همچنان با همان کلید افشاشده امضا شده‌اند.

برای انتشار واقعی باید با برنامه‌ای جداگانه دربارهٔ مهاجرت توافق شود: کلید تازه را خارج مخزن و در محل امن نگه دارید، دسترسی‌های انتشار را محدود کنید و بر اساس کانال توزیع، Play App Signing یا چرخش امضای سازگار با نسخه‌های اندروید را بررسی کنید. دستگاه‌های Android 8.1 و پایین‌تر چرخش گواهی v3 را پشتیبانی نمی‌کنند؛ تغییر سادهٔ کلید، به‌روزرسانی نصب‌های قبلی را رد می‌کند. هرگونه مهاجرت باید قبل از اقدام با کاربر هماهنگ و روی دستگاه‌ها آزموده شود. گذرواژه یا کلید خصوصی نباید در گفتگو ارسال شود. [راهنمای رسمی امضا](https://developer.android.com/studio/publish/app-signing)، [apksigner و چرخش](https://developer.android.com/tools/apksigner)، [محدودیت Android 8.1](https://developer.android.com/about/versions/pie/android-9.0).

## مانیفست و مجوزها

- بازی مجوز `INTERNET`، دسترسی فایل، موقعیت، دوربین، مخاطبان یا تلفن درخواست نمی‌کند. فقط Activity لانچر صادرشده لازم است؛ سرویس، گیرنده و provider در مانیفست بازی تعریف نشده‌اند. مانیفست نهایی APK نیز در CI بررسی می‌شود.
- `allowBackup=false` و `usesCleartextTraffic=false` صریح شدند. بکاپ خودکار ابری تنظیمات و رکوردها در نسخهٔ جدید غیرفعال می‌شود؛ به‌روزرسانی سازگار به‌خودی‌خود داده‌های محلی را پاک نمی‌کند، ولی کلید جدید نصب مستقیم روی نسخهٔ قدیمی را با مشکل روبه‌رو می‌کند. رفتار انتقال دستگاه در نسخه‌ها و سازندگان مختلف اندروید باید جداگانه آزموده شود.
- نسخهٔ Release قابل دیباگ نیست و انتظار فقط یک Activity و نداشتن permission/service/receiver/provider در gate ساخت بررسی می‌شود. نمونهٔ مستقل `app` نیز backup و cleartext را غیرفعال کرده است.

## حریم خصوصی و جریان داده

کد بازی از `SharedPreferences` در حالت خصوصی برای رکورد، درجه، زبان، تنظیم صدا، تم و ظاهر استفاده می‌کند. موسیقی، افکت‌ها و فونت داخل بسته‌اند. در بازبینی ایستا هیچ کد شبکه، تحلیل کاربر، ردیابی تبلیغاتی، دریافت شناسهٔ دستگاه یا دسترسی به اطلاعات شخصی مشاهده نشد؛ بدون مجوز اینترنت نیز برنامه در حالت عادی نمی‌تواند اتصال شبکهٔ مستقیم داشته باشد. نام و ایمیل سازنده و متادیتای موجود در فایل‌های صوتی، محتوای همراه برنامه و قابل استخراج از APK هستند، نه اطلاعاتی که از بازیکن جمع‌آوری شده باشند. برنامهٔ **نمونهٔ جداگانه** `app` مدل و نسخهٔ اندروید را روی صفحهٔ خود نمایش می‌دهد؛ این رفتار متعلق به APK بازی نیست و کد ارسالی برای آن یافت نشد.

## رفتار پس‌زمینه

پخش موسیقی در `onPause` متوقف و تمرکز صوتی رها می‌شود؛ در نابودی Activity منابع آزاد می‌شوند. حلقهٔ بازی اکنون تنها در Activity فعال و با سطح معتبر شروع می‌شود و هنگام `onPause` یا تخریب سطح متوقف می‌شود. سرویس پس‌زمینه، کار زمان‌بندی‌شده و مجوز شبکه در بازی مشاهده نشد. این نتایج از بازبینی کد هستند و با تست چرخهٔ عمر/مصرف باتری روی دستگاه تأیید نشده‌اند؛ جلوهٔ صوتی کوتاهی که پیش از خروج آغاز شده ممکن است تا پایان همان نمونه ادامه یابد.

## زنجیرهٔ ساخت و وابستگی‌ها

بازی وابستگی runtime شخص ثالث اعلام نکرده است؛ فریم‌ورک اندروید و منابع داخلی استفاده می‌شوند. ابزار ساخت از Android Gradle Plugin 8.5.2 و Gradle 8.7 به 8.13.2 و 8.13 ارتقا یافته، و `compileSdk/targetSdk` بازی به ۳۶ رسیده است؛ حداقل SDK همچنان ۲۱ است. در پیکربندی پیشنهادی CI قرار است درخت وابستگی runtime و build ثبت شود و در صورت وجود وابستگی runtime غیرمنتظره متوقف شود؛ این رفتار هنوز با Gradle واقعی آزموده نشده است. استعلام GitHub Advisory برای مختصات مستقیم `com.android.tools.build:gradle@8.13.2` نتیجه‌ای نشان نداد؛ این **به معنی نبود آسیب‌پذیری در وابستگی‌های انتقالی، ابزارهای Google، JDK، Android SDK یا runner نیست**. اسکن جامع SCA/SBOM و به‌روزرسانی مداوم همچنان لازم است.

Actionهای workflowها به commit ثابت شده‌اند؛ workflow بازی از ذخیرهٔ credential توسط checkout جلوگیری می‌کند؛ اجرای آن فقط دستی است و انتشار خودکار یا push ندارد و تنها پس از موفقیت بررسی‌ها artifact می‌سازد. کنترل دسترسی شاخه، مرور تغییرات، حفاظت release و امنیت حساب GitHub همچنان ضروری‌اند. Dependency verification/lockfile کامل برای artifactهای Gradle هنوز پیکربندی نشده و وابستگی به مخازن و زنجیرهٔ ساخت از ریسک‌های باقی‌مانده است.

ابزار `tools/make_fonts.py` پیش‌تر از cache اشتراکی `/tmp/package` و استخراج مسیرهای آرشیو استفاده می‌کرد. اکنون آرشیو با SHA-512 ثابت و محدودیت حجم کنترل می‌شود و فقط سه عضو دقیق از نوع فایل معمولی در پوشهٔ موقت خصوصی خوانده می‌شوند؛ این ابزار بخشی از اجرای APK نیست. فونت‌های خروجی با خروجی قبلی یکسان بررسی شدند.

## امضا، انتشار و سازگاری

Release با طرح‌های امضای v1، v2 و v3 پیکربندی شده است؛ gate ساخت موفقیت `apksigner`، گواهی مورد انتظار، تعداد امضاکننده و چند قاعدهٔ مانیفست را بررسی می‌کند. v1 برای Android 5 و 6 لازم است؛ امضای معتبر به معنی بی‌خطر بودن کد یا محرمانه بودن کلید نیست. Android API 21 حداقل نصب و API 36 هدف اعلامی است؛ وجود touchscreen الزامی است. سازگاری واقعی، edge-to-edge، صدا و به‌روزرسانی در Android 5 تا 16 بدون دستگاه یا شبیه‌ساز بررسی نشده‌اند. هدف API 36 به‌تنهایی تضمین پذیرش Google Play یا Play Protect نیست. هیچ هشدار امنیتی دور زده نشده است. [الزامات target SDK گوگل](https://developer.android.com/google/play/requirements/target-sdk)، [سازگاری AGP 8.13](https://developer.android.com/build/releases/agp-8-13-0-release-notes).

## آزمون‌ها و محدودیت‌ها

شبیه‌ساز مولد و تست fixture برای رد permission/debuggable/امضای نامعتبر محلی موفق شدند. در اجرای CI شمارهٔ 43012822644، آزمون‌های جاوا و شبیه‌ساز، بازرسی وابستگی runtime، ساخت برنامهٔ نمونه و APK debug موفق شدند؛ مرحلهٔ ساخت و بررسی Release شکست خورد و APK Release یا بررسی آن تولید نشد. دریافت جزئیات log با EOF شکست خورد و علت دقیق مرحله هنوز تأیید نشده است. کنترل آسیب‌پذیری‌های همهٔ وابستگی‌های انتقالی، malware scanning مستقل برای فایل‌های تصویری و صوتی، آزمون پویا و تحلیل شبکهٔ واقعی، بررسی Play Protect و تست روی مجموعه‌ای از دستگاه‌ها انجام نشده‌اند. ریسک کلید عمومی **بحرانی و حل‌نشده** است؛ برنامه نباید صرفاً بر اساس این گزارش «کاملاً امن» نامیده شود.

## وضعیت کنونی

تا این لحظه کلید تازه ساخته نشده، وضعیت Secrets قابل مشاهده نیست، build و بررسی APK Release ۱٫۹ و نصب شبیه‌ساز انجام نشده است. دسترسی GitHub API به Actions Secrets خطای ۴۰۳ داد. اجرای CI شمارهٔ 43012822644 در مرحلهٔ Release شکست خورد و دریافت log با EOF ناموفق بود؛ علت دقیق شکست تأیید نشده است. قالب CI و آزمون‌های fixture جایگزین اجرای واقعی نیستند.
