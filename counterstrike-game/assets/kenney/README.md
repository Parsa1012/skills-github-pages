# دارایی‌های سه‌بعدی و صوتی Kenney (CC0)

تمام مدل‌ها و جلوه‌های صوتی داخل این پوشه با مجوز رسمی **CC0 1.0 Universal (Public Domain)** از بسته‌های Kenney تهیه شده‌اند:

- `blocky_characters/` ← مدل‌های سربازان نظامی متحرک (`character-j.glb` و غیره) همراه با پوسته‌های استتار سفارشی (`Textures/skin_*.png`)
- `weapon/` ← سلاح‌های گرم نظامی واقعی (`machinegun.glb`, `uziLongSilencer.glb`, `shotgun.glb`, `sniper.glb`, `grenade.glb`, `ammo_machinegun.glb`)
- `survival/` ← موانع تاکتیکی، جعبه‌های چوبی مهمات، دیوارچه‌های مستحکم و بشکه‌های سوخت انفجاری (`box.glb`, `barrel.glb`, `fence-fortified.glb`)
- `retro_urban/` ← سنگرهای بتنی مسلح، پالت‌های تدارکاتی و تیرهای چراغ پایگاه (`detail-barrier-strong-type-a.glb`, `detail-barrier-strong-damaged.glb`, `detail-light-double.glb`, `pallet.glb`)
- `mini_arena/` & `platformer/` ← دیواره‌های پیرامونی (`wall.glb`, `wall-corner.glb`) و پرچم تصرف منطقه (`flag.glb`)
- `audio/` ← افکت‌های تکمیلی قدم‌زدن، فرود، تعویض سلاح و اصابت (`walking.ogg`, `land.ogg`, `weapon_change.ogg`, `enemy_hurt.ogg`, `enemy_destroy.ogg`)
