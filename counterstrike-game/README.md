# کانتر استرایک آرنا (Counterstrike Arena — بازی موبایل 2.5D آفلاین با Godot 4.3)

پروژه مستقل و کاملا آفلاین **کانتر استرایک آرنا** در مسیر `counterstrike-game/` برای اجرای روان روی **Samsung Galaxy A32 (اندروید، معماری `arm64-v8a`)** با موتور **Godot 4.3**، رندرر سبک **GL Compatibility**، رابط کاربری تمام‌فارسی (RTL + فونت آزاد **Vazirmatn**) و نمای دوربین زاویه‌دار **BombSquad (`57.5°`)** توسعه داده شده است.

## وضعیت فعلی: فاز ۲ (شخصیت سه‌بعدی، حرکت، محیط و کنترل لمسی موبایل)
- **دوربین BombSquad (فاز ۱ + ۲):** زاویه ثابت `57.5°` (قابل تنظیم در `ProjectSettings -> arena_camera/*`) بدون چرخش ۳۶۰ درجه آزاد، دنبال‌کننده نرم بازیکن همراه با پیش‌بینی جهت حرکت و محدوده زمین.
- **کنترل لمسی چندلمسی (Multi-Touch):**
  - **جوی‌استیک سمت چپ (`VirtualJoystick`):** حرکت آزاد با کنترل سرعت (راه‌رفتن تا دویدن بر اساس میزان کشش انگشت) و پشتیبانی کامل از هم‌زمانی لمس.
  - **جوی‌استیک سمت راست (`VirtualJoystick`):** نشانه روی مستقل در ۳۶۰ درجه سطح زمین + نشانگر لیزری سه‌بعدی مقابل شخصیت.
  - **دو حالت قابل انتخاب:** «دو جوی‌استیک هم‌زمان» (کشیدن جوی‌استیک راست به حلقه بیرونی برای شلیک) یا «دکمه شلیک جداگانه» (`TouchFirePad` چندلمسی).
- **شخصیت بازیکن (`CharacterBody3D`) و میدان نبرد (`arena_sector_01.tscn`):**
  - برخورد فیزیکی با دیواره‌ها، موانع، جعبه‌ها، ستون‌ها، شیب‌راه‌های سکو میانی و بات‌های هدف، همراه با تشخیص ورود به **منطقه الف** و **منطقه ب** (`Area3D`).
  - **آماده جایگزینی مستقیم مدل‌های Kenney:** پوشه `assets/kenney/` (`characters/` و `environment/`) و پارامتر `kenney_character_scene` برای اتصال فوری فایل‌های `.glb` / `.tscn` بسته‌های Kenney بدون تغییر کد گیم‌پلی.
- **صدای اختصاصی پروژه:** افکت‌های رابط کاربری اختصاصی و جدید (`sfx_ui_tap.wav`, `sfx_ui_switch.wav`, `sfx_ui_confirm.wav`) بدون استفاده از هیچ فایل صوتی یا رابطی از پروژه قبلی.

## ساخت APK دیباگ اندروید در GitHub Actions
ورک‌فلو `.github/workflows/build-counterstrike-apk.yml` با **Godot 4.3-stable**، بررسی تمام صحنه‌ها (`boot`, `main_menu`, `camera_angle_test`, `arena_sector_01`)، بررسی تک‌معماری `arm64-v8a`، بررسی فونت فارسی و فایل‌های صوتی اختصاصی، و امضای `apksigner` خروجی `counterstrike-arena-debug-arm64.apk` را تولید می‌کند.
