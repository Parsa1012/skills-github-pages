# کانتر استرایک آرنا (Counterstrike Arena — بازی موبایل 2.5D آفلاین با Godot 4.3)

بازی اکشن آرکید آفلاین با گرافیک Low-Poly، مدل‌های سه‌بعدی و صوتی رسمی **Kenney**، رابط کاربری تمام‌فارسی (RTL + فونت آزاد **Vazirmatn**) و بهینه‌سازی اختصاصی برای **Samsung Galaxy A32 (`arm64-v8a`, GL Compatibility, هدف پایدار 30 FPS)**.

## قابلیت‌های پیاده‌سازی‌شده
- **شخصیت‌ها و محیط سه‌بعدی Kenney (`assets/kenney/`):**
  - بازیکن با مدل متحرک `character-soldier.glb` (`idle`, `walk`, `sprint`) و سلاح‌های قابل تعویض `blaster.glb` و `blaster-repeater.glb`
  - زمین نبرد `arena_sector_01.tscn` ساخته شده با قطعات محیطی `wall-low.glb`, `wall-high.glb`, `column.glb`, `column-damaged.glb`, `block.glb`, `bricks.glb`, `banner.glb` و `flag.glb`
- **دوربین زاویه‌دار BombSquad (`57.5°`):** زاویه ثابت بدون چرخش ۳۶۰ درجه آزاد، تعقیب نرم با پیش‌بینی جهت حرکت و محدوده زمین (`ProjectSettings -> arena_camera/*`)
- **کنترل لمسی چندلمسی (Multi-Touch):**
  - جوی‌استیک چپ برای حرکت و سرعت (راه‌رفتن/دویدن) + جوی‌استیک راست برای نشانه‌گیری ۳۶۰ درجه و شلیک (همراه با حالت جایگزین «دکمه شلیک جداگانه» و دکمه‌های لمسی «تغییر سلاح» و «شارژ»)
- **مبارزه و هوش مصنوعی آفلاین:**
  - شلیک گلوله‌های انرژی استخری (`PoolManager` + `EnergyProjectile` با RayCast پیوسته) و افکت برخورد (`ImpactFlash`)
  - ۳ بات پهپاد دشمن (`enemy-flying.glb` با `ArenaBot`) دارای گشت‌زنی، تشخیص خط دید، تیراندازی، نوار جان سه‌بعدی، بازگشت خودکار و شمارش امتیاز آبی/نارنجی
- **صوت تمیز و مستقل:** فقط افکت‌های اختصاصی UI همین پروژه (`sfx_ui_*.wav`) و افکت‌های آزاد Kenney (`.ogg`) در `assets/kenney/audio/` (بدون استفاده از هیچ دارایی یا کدی از پروژه قبل).
