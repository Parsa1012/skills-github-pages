# کانتر استرایک آرنا (Counterstrike Arena — نسخه ۰.۸، بازی اکشن ۲.۵ بعدی آفلاین با Godot 4.3)

بازی اکشن آرکید ۳بعدی و تمام‌آفلاین با گرافیک Low-Poly، مدل‌ها و صداهای رسمی **Kenney**، رابط کاربری فارسی (RTL + فونت آزاد **Vazirmatn**) و بهینه‌سازی اختصاصی برای **Samsung Galaxy A32 (`arm64-v8a`, GL Compatibility)**.

## ساختار و قابلیت‌های اصلی
- **۲ نقشه متمایز نبرد (`scenes/maps/`):**
  - `arena_sector_01.tscn`: پایگاه فولادی (۳۲×۲۴ متر، سکوی مرتفع مرکزی، رمپ و جعبه‌های انرژی انفجاری)
  - `arena_sector_02.tscn`: دژ مرکزی (۳۴×۲۴ متر، ۴ ستون پوششی، سنگرهای جناحی و گلوگاه‌های انفجاری)
- **۳ حالت بازی (`data/modes/`):** کنترل مناطق (`zone_control`)، یورش امتیاز (`team_score_rush`) و رعد منطقه (`zone_blitz`)
- **۴ سلاح انرژی (`data/blasters/`) + سلاح دوم بمب پالس (`PulseBomb`):**
  - پالس بلاستر، رگبار انرژی، پخش‌کننده پلاسما (۳ گوی همزمان) و ریل‌گان کمانی (نفوذ در هدف) با رانش فیزیکی متفاوت
  - بمب پالس تاکتیکی (پرتاب سهموی با انفجار منطقه‌ای AoE) و جعبه‌های انرژی انفجاری واکنش‌زنجیره‌ای (`ExplosiveCrate`)
- **هوش مصنوعی تاکتیکی و تنظیم سختی (`scripts/ai/arena_bot.gd`):**
  - ۱ هم‌تیمی آبی + ۳ دشمن نارنجی (پهپاد تاکتیکی، دیده‌بان سریع، نگهبان سنگین دوگانه) با هدایت مانع‌گریز ۳شعاعی، پرهیز از بمب، هدف‌گیری هوشمند جعبه‌های انفجاری، جداسازی تیمی و ۳ سطح سختی (`آسان` / `متعادل` / `حرفه‌ای`)
- **رابط کاربری نبرد و حس ضربه (Game Juice):**
  - کنترل چندلمسی شناور، دکمه‌های جهش تاکتیکی (`Dash` با عبور از گلوله) و بمب پالس
  - رادار زنده ۲بعدی (`TacticalRadar`)، اعداد آسیب شناور سه‌بعدی به دوبعدی (`DamageNumbersOverlay`)، کمان جهت‌نمای آسیب (`HitDirectionIndicator`)، خوراک کشته‌ها و سیستم رتبه و تجربه آفلاین (`SaveManager`)
